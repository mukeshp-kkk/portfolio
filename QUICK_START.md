# 🚀 Quick Start - Deploy to Render in 5 Minutes

## Copy These Commands

### 1️⃣ Render Build Command
```
npm install && npm run build
```

### 2️⃣ Render Start Command
```
npm start
```

### 3️⃣ Environment Variables

Copy your credentials from your local `.env` file into Render's Environment section.

Required variables:
```
NODE_ENV=production
EMAIL_HOST=(from your .env)
EMAIL_PORT=(from your .env)
EMAIL_SECURE=(from your .env)
EMAIL_USER=(from your .env)
EMAIL_PASS=(from your .env)
EMAIL_FROM=(from your .env)
BREVO_API_KEY=(from your .env)
BREVO_SENDER_EMAIL=(from your .env)
BREVO_SENDER_NAME=(from your .env)
CONTACT_NOTIFY_EMAIL=(from your .env)
```

**Note:** Do NOT commit your actual credentials to Git. Use your local `.env` file values.

---

## ✅ That's It!

Just copy these three things into Render and your portfolio will be live! 🎉
